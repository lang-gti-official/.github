GTI is an independent, statically typed systems programming language with C++-familiar syntax, explicit ownership, and deterministic cleanup. It is designed for programs that need control over memory, object lifetimes, and runtime costs.

### Built for systems programming

- **Explicit ownership and lifetimes** — make resource management part of the language.
- **Deterministic cleanup** — release resources when their owners leave scope.
- **Native compilation** — LLVM is the primary development backend.
- **A growing toolchain** — compiler, package management, formatter, and language server.
